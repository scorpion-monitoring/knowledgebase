## Definition

KPI standardisation is the process in which best practices emerge among providers and KPIs are defined in terms of what is tracked, how it is measured and on which scale.

## Explanation

The source describes standardisation as the process "whereby best practices emerge among service providers and KPIs are defined in terms of which KPIs are tracked, which method is used to measure KPIs, and on which scale they are measured (e.g. cumulatively or per time interval)".

Read against the terms of this KB, <Term id="kpi-harmonisation" /> fixes the set of <Term id="indicator" />s. Standardisation fixes the <Term id="measurement" /> and the <Term id="metric" /> as well. In terms of a KPI specification it covers the data source, the calculation rule and the frequency. Only standardised KPIs can be aggregated across providers in a meaningful way.

Neither term includes a <Term id="target" />. A set of KPIs can be fully standardised without fixing which values a service is expected to reach.

The providers of the previous example agree that "unique visitors per month" is counted by web analytics with bot traffic removed, and that each provider reports the value per month and not as a running total. The values are now comparable and can be added up.

## Not to be confused with

- <Term id="kpi-harmonisation" />: agreement on the set only.
- Standardisation by a formal standards body. Here it means agreement among providers, which may or may not become a formal standard.
