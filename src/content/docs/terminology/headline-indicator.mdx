## Definition

A headline indicator is a single indicator chosen to summarise the state of a whole indicator framework or topic.

## Explanation

No single standard definition of "headline indicator" exists. Statistical offices use "headline" for the few indicators that monitor central objectives of a policy. Eurostat lists "headline" next to "principal", "key", "core" and "main" as adjectives that authors attach to "indicator" without a fixed distinction. The definition above is therefore the KB's working definition.

A headline indicator is chosen, not calculated. A group decides that one <Term id="indicator" /> in an <Term id="indicator-framework" /> is the best single sign of overall progress. The choice is part of the framework and is open to review. Where a summary is calculated from many values instead, the KB calls it an <Term id="aggregation" />.

A headline indicator is also not the same as a <Term id="key-performance-indicator" />. Many indicators in a framework can be key. Only one is the headline.

A single number hides detail. Readers of a headline indicator should be able to reach the other indicators behind it.

## Example

An indicator framework for a service has indicators for user requests, publications, availability and user satisfaction. The governing group names the number of publications acknowledging the service as the headline indicator. The annual summary shows it first, with links to the other indicators.

## Not to be confused with

- key performance indicator: an indicator that is critical to success. A framework can have several.
- aggregation: a value calculated from many values. A headline indicator is one chosen indicator.
- indicator framework: the whole set. The headline indicator is one member.
