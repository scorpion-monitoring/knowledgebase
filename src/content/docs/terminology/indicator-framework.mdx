## Definition

An indicator framework is a named set of indicators, each with a specification, that a community agrees to use together to monitor a defined kind of entity.

## Explanation

A single <Term id="indicator" /> says little. A framework collects the indicators that together describe an entity, such as a service or an infrastructure. For each indicator it fixes the name, the description, the <Term id="value-type" />, the <Term id="unit-of-measurement" /> and the way to obtain the value.

A framework can also state which indicators are expected from whom. This expectation is the <Term id="necessity-level" />. It can group its indicators into <Term id="thematic-category" /> groups. It can name a <Term id="headline-indicator" />.

A framework makes values from different contributors comparable. It is the usual result of <Term id="kpi-harmonisation" />.

Many communities use other names. "Indicator set" is common. "KPI set" is a common informal name, because the members are often called key performance indicators. The KB prefers "indicator framework". It uses "framework" because the set carries specifications and expectations, not only a list of names.

The ESFRI working group on monitoring is a well-known example of such work. It proposed a common set of key performance indicators for European research infrastructures.

## Example

A group of service providers agrees on a framework for data services. It lists eight indicators: user requests, registered users, publications that acknowledge the service, availability, response time, user satisfaction, training events and data volume. Each indicator has a description, a unit and a necessity level. New service providers adopt the framework as it is.

## Not to be confused with

- indicator: one member of a framework.
- <Term id="indicator-classes" />: a classification of indicators by what they show, not a set of specified indicators.
- thematic category: a grouping inside a framework.
- A dashboard: a display of values. A framework defines what the values are.
