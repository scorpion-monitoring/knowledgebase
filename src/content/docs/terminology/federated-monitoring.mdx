## Definition

In federated monitoring, autonomous service providers measure indicators locally with their own tools and keep control of their measurements, and a coordinating body collects the reported values.

## Explanation

**This is a working definition of one author, not a formal standard.** It comes from the doctoral thesis of the author of this knowledge base (unpublished) and follows established practice.

In a federated infrastructure no single organisation carries out the <Term id="monitoring" />. Each provider measures locally, with its own tools. The coordinating body collects the reported values for <Term id="reporting" /> and <Term id="evaluation" />, and does not need access to raw data such as access logs.

Two practices show the pattern. ELIXIR collects usage statistics for its Core Data Resources locally at each host institute and collates them at the ELIXIR Hub. The German Network for Bioinformatics Infrastructure (de.NBI) lets service providers retain control over their metrics while supporting centralised reporting.

Values from several providers can be combined only if the providers report the same indicators in the same way. That requires agreement, described by <Term id="kpi-harmonisation" /> and <Term id="kpi-standardisation" />.

## Example

Twenty providers each run their own web analytics. At the end of each month every provider reports the number of unique visitors to the coordinating office. The office adds the values and publishes the total. It never sees the providers' access logs.

## Not to be confused with

- Federated learning or federated identity, which are other uses of "federated".
- Central monitoring, where one organisation runs the probes and holds the raw data.
