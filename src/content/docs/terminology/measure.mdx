## Definition

A measure is a variable to which a value is assigned as the result of a measurement.

## Explanation

The definition above is the one used in the measurement standard ISO/IEC/IEEE 15939. The standard names a base measure, which captures one property directly, and a derived measure, which combines two or more other measures. In the standard, <Term id="indicator" /> is a further kind of measure.

Usage varies. In everyday language, "measure" also means an action taken, as in "a measure to reduce cost", and many authors use "measure", "metric" and "indicator" as synonyms. The KB uses "measure" only for the variable. It uses <Term id="metric" /> for the defined way of calculating a quantity and indicator for a quantity chosen to show progress towards an objective.

A measure always has a <Term id="unit-of-measurement" />, or it is a count or a category. The <Term id="measurement" /> is the act or record that gives the measure a value.

## Example

"Number of user requests" is a base measure. "Number of user requests divided by number of registered users" is a derived measure. A service provider records the first value each month and calculates the second.

## Not to be confused with

- measurement: the act of measuring, or its recorded result for one point in time. A measure is the variable that holds the result.
- metric: the defined method of calculation.
- indicator: a measure chosen to show progress, with context such as a target.
- An action taken to reach a goal, as in "a cost-saving measure". The KB does not use "measure" in this sense.
