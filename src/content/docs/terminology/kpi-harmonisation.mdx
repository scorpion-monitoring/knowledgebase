## Definition

KPI harmonisation is the process of reaching consensus among all service providers on a set of KPIs, with each provider measuring its values through its own monitoring system.

## Explanation

The source describes harmonisation as agreement among all service providers on a set of KPIs, which they report through their own KPI monitoring. In the quality cycle it belongs to planning. In a federation planning is not decided by one organisation and has to be negotiated among the providers.

Harmonisation fixes the set of <Term id="indicator" />s. It does not fix how each one is measured. That is the extra step of <Term id="kpi-standardisation" />. Harmonisation does not include a <Term id="target" /> either.

## Example

Providers of web applications in a network agree that all of them report "unique visitors per month". One uses web analytics and another uses log analysis. The set of indicators is harmonised. The values are not yet comparable.

## Not to be confused with

- <Term id="kpi-standardisation" />: also fixes the measurement and the metric.
- Harmonisation of data or schemas, which concerns formats.
