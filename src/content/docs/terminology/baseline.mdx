## Definition

A baseline is the value of an indicator at the start of a monitoring period or before an intervention, against which later values are compared.

## Explanation

A baseline gives a starting point. Without it you cannot say whether a later <Term id="observation" /> is an improvement. If a service had 800 users when monitoring began and has 1,000 now, the change is 200 users. The baseline is the 800.

The evaluation community uses the term for a study as well as a value. A baseline study describes the situation before an intervention, so that progress can be assessed or comparisons made. Monitoring practice uses the value from that study. The KB uses the term for the value.

The baseline is a past or initial value. A <Term id="target" /> is a future value. A <Term id="threshold" /> is a limit that triggers an action. Progress towards a target is often expressed relative to the baseline: how much of the distance from baseline to target has been covered.

The baseline is fixed once set. If you later find that it was wrong, correct it and record the change in the <Term id="data-provenance" />.

## Example

A research infrastructure starts to monitor the number of yearly user registrations of a service in 2023. The 2023 value, 800, is the baseline. In 2025 the value is 1,000, and the target is 1,500. Progress is 200 of the 700 users between baseline and target.

## Not to be confused with

- <Term id="target" />: the value that you want to reach, not the starting value.
- <Term id="threshold" />: a limit that signals a problem or a decision point, not a starting point.
- Benchmark: a reference value from other organisations, not from your own start.
