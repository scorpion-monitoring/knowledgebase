## Definition

An open source licence is a legal licence that lets anyone use, study, modify and redistribute software and its source code under stated conditions.

## Explanation

Software is protected by copyright by default. Without a licence, other people may not copy or change it. An open source licence is the copyright holder's written permission to do those things, with conditions attached.

The conditions differ. A permissive licence asks mainly for attribution. A copyleft licence also requires that changed versions are shared under the same terms. Both kinds can be open source.

Two communities use the idea with slightly different words: "open source" and "free software". Their lists of acceptable licences overlap strongly but are not identical. The KB uses "open source licence" and, when it needs to say that a licence has been checked against the Open Source Definition, <Term id="osi-approval" />.

A licence says nothing by itself about how it is named in metadata. A <Term id="spdx-licence-identifier" /> gives it a short, machine-readable name.

## Example

A research infrastructure publishes a data-analysis tool that its service providers run. It releases the source code under a permissive open source licence. Partner institutes can copy the tool, adapt it to their own workflow and publish their changes. The infrastructure records the licence for the tool so that usage reports can state which resources are open.

## Not to be confused with

- Open access: free reading of publications, which concerns publications, not software terms.
- Open data licences: licences for data or content, such as those that grant reuse of a dataset. They are a separate family from software licences.
- Freeware or source-available terms: the code or programme can be used or read, but one or more freedoms in the Open Source Definition are missing.
- <Term id="osi-approval" />: a status of a licence, not a type of licence.

## References

- Open Source Initiative, "The Open Source Definition", version 1.9, [https://opensource.org/osd](https://opensource.org/osd) — states the criteria that distribution terms must meet to count as open source, whose criteria apply to the distribution terms of open source software.
- Open Source Initiative, "Licenses", [https://opensource.org/licenses](https://opensource.org/licenses) — states that "Open source licenses are licenses that comply with the Open Source Definition."
