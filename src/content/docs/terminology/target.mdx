## Definition

A target is the value of an indicator that a service or organisation aims to reach by a stated time, agreed in advance.

## Explanation

A target turns a number into a goal. It lets you say whether a <Term id="observation" /> is good enough. A target belongs to one <Term id="indicator" /> and one period. It has the same <Term id="unit-of-measurement" /> as the indicator.

The target is the counterpart of the service level in a service level agreement (SLA). The SLA states the level of performance that a provider agrees to deliver, for example availability of 99 per cent. In service management the agreed level is called a service level target. Evaluation and results-based management use "target" for the planned result of an intervention.

A target is not part of the definition of an indicator in the same way as its name or unit. Frameworks for <Term id="key-performance-indicator" /> management list the specification of an indicator with features such as identifier, name, description, calculation rule, value type, unit, frequency, target and data source. The target is the one feature that organisations often set locally. A set of indicators can be standardised, so that everyone calculates them the same way, without fixing the target values. Each organisation then sets its own targets. See <Term id="kpi-standardisation" /> and <Term id="indicator-framework" />.

## Example

A research infrastructure sets the target for the indicator "Service availability" at 99 per cent per month. A provider reports 98.2 per cent for March. The target is not met. Another infrastructure uses the same indicator with a target of 95 per cent, because its services are less critical.

## Not to be confused with

- <Term id="baseline" />: the starting value. The target is the intended end value.
- <Term id="threshold" />: a limit that triggers a warning or action. A target is a goal. A threshold is a boundary.
- <Term id="observation" />: a value that was recorded. A target is a value that is planned.
