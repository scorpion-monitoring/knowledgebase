## Definition

A citation is a formal reference from one scholarly work to an earlier work that it builds on, quotes or discusses.

## Explanation

A citing <Term id="publication" /> lists the works it refers to. Each listed work receives one citation from it. Linking works with a <Term id="doi" /> or another persistent identifier makes the match reliable.

Crossref creates links between works from the references that its members deposit with their records. It checks them against registered content and records the relationship when they match.

"Citation" has two senses. It can mean the reference in the citing work, or the link between the two works. The KB uses the link sense, which is what is counted in a <Term id="citation-count" />.

A citation does not say whether the citing work agrees, disagrees or only mentions. It also does not show that the cited work is good.

## Example

A review article lists 60 earlier articles in its reference list. Each of these 60 articles receives one citation from the review.

## Not to be confused with

- A mention of a service in text or acknowledgements, which has no formal reference and no identifier.
- A <Term id="citation-count" />, which is the total number of citations a work has received.
- A bibliographic reference string, which is the text form of one entry in a reference list.
